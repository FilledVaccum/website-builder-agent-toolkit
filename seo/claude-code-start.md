# Claude Code — where to start

For Claude Code, start with [zubair-trabzada/geo-seo-claude](https://github.com/zubair-trabzada/geo-seo-claude) if the goal is GEO, and [AgriciDaniel/claude-seo](https://github.com/AgriciDaniel/claude-seo) if you also want a full technical SEO audit. Both are skill plugins and do not require a vendor account.

Add [every-app/open-seo](https://github.com/every-app/open-seo) or [AminForou/mcp-gsc](https://github.com/AminForou/mcp-gsc) when the agent needs live keyword, rank, or Search Console data. OpenSEO is the popular all-in-one MCP. mcp-gsc is the one that stays on Google's own API.
