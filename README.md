# Website-Building Toolkit — Index

Curated skills, GitHub repos and MCP servers for building a website end to end with a coding agent. Researched 2026-10-11. All entries are free to use (open source, or hosted with a free tier); costs are in `pricing/`.

## Layout

| Path | What's in it | Use it when |
|---|---|---|
| `AGENTS.md` / `CLAUDE.md` | Routing rules for the coding agent | Always read first |
| `playbook/` | Principles, top pick per stage, minimal + indie stacks, gotchas, 10 Claude repos that earn their place | Deciding *what* to use |
| `catalog/stages/NN-*.md` | Per-stage tables: A) Skills, B) Repos, C) Free MCPs (name, URL, ★, last push) | Looking up tools for one stage |
| `catalog/01-quick-install-starter-set.md` | Best skill + repo + MCP per stage, with install commands | Setting up a project fast |
| `guides/NN-*.md` | Narrative per-stage detail, plus boilerplates, AI builders, meta-resources | Needing more context than the table |
| `pricing/pricing.md` | Free vs paid, limits, cheapest launch stack | Cost / commercial-use questions |
| `seo/` | SEO + GEO (AI search) tools, install notes | SEO / `llms.txt` / schema work |
| `library/` | Every shared resource as a tagged card (type, stage, task, content, platform, cost, license, trust); generated `INDEX.md` with by-tag views | Finding or filing any tool, repo, skill or guide |
| `design/` | Design inspiration galleries, templates, asset packs, AI site builders (prices + licence cautions) | Picking design references or assets |
| `content/` | Producing content: code-rendered video studio workflow | Making video or other media with agents |
| `marketing/` | Post-launch promotion: Claude Project that picks weekly TikTok/Reels trends and writes shot lists | Social video content |
| `reference/` | Sources and registries used | Finding more |
